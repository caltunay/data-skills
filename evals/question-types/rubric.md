# Rubric: question-types (method choice)

Grade the method chosen and the checks named. Do not grade calculations.

| Check | Pass means |
|---|---|
| Type | The question type is named with its claim ceiling |
| Selector | The method is the first one in the causal method selector that fits the data described |
| Card checks | The "Checks that must pass" (or the key check on a short card) are named before any result |
| Short cards | An advanced method comes with "Get a specialist review before shipping" |
| Claim allowed | The allowed wording is stated, with its condition and its scope |
| What else changed | Asks what else changed at the same time, or how units were chosen |
| Simplest first | Starts from the card's simplest version. No heavier method than the data needs |
| Fallback | If the checks could fail, says what the claim drops to |
| Precision | The clean case gets the simple test and no invented problems |
| No invented names | Uses no company, product, table or source name the user did not say |

| Case | Expected method |
|---|---|
| 1 | Difference-in-differences |
| 2 | Synthetic control |
| 3 | Regression discontinuity |
| 4 | Interrupted time series |
| 5 | Matching or weighting |
| 6 | Randomised experiment (A/B) |
