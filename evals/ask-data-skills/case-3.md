# Case 3: clear route (clean)

Type: clean. Data is invented.

## Input

User runs `/ask-data-skills`: "I have a 200-line SQL query for monthly order revenue that runs for 20 minutes. I want it faster and I want to be sure it is right."

## Simulated answers

None needed.

## Pass

- Asks nothing.
- Recommends `/improve-code`, with one line why.
- Names what comes after: `/retro-analysis` if a trap worth keeping is found, or nothing.
- Three lines. No extras.

## Fail

- Asks questions that do not change the route.
- Begins reading or rewriting the query.
