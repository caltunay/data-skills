# Rubric: /storytell

| Check | Pass means |
|---|---|
| Start check | Says in one line which of `DATA-MAP.md`, `analysis.md` and `readout.md` were found. Does not offer setup |
| Final first | A draft or unmarked readout is called out, with `/review-analysis` suggested. Continues only if told to, and marks the output as from an unreviewed readout |
| Asks once | Audience and format asked in one round, only if not already given |
| Answer first | The first line or slide is the answer |
| Uncertainty kept | Every number keeps its uncertainty from the readout |
| Ceiling kept | No claim above the ceiling in `analysis.md`. Shorter words are not stronger words |
| Caveats kept | Every caveat survives, in plain words |
| Nothing new | No number, reason or recommendation that the source does not hold |
| Exec | No jargon. Under 150 words before the appendix |
| Slides | At most 5. Each title states the takeaway. One chart suggestion per slide that passes the `viz` checks |
| File | `readout-<audience>.md` next to the readout |
| Precision | The clean case gets no questions and no invented caveats |
| No early tool call | No connector or data tool call. This step runs no queries |
| Chat-app handoff | With no project folder, offers the new file as a download and says to save it to Project files |
| No invented names | Uses no company, product, table or source name the user did not say |
