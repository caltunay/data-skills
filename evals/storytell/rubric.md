# Rubric: /storytell

| Check | Pass means |
|---|---|
| Start check | Says in one line which of `DATA-MAP.md`, `analysis.md` and `readout.md` were found. Does not offer setup |
| Final first | A draft or unmarked readout is called out, with `/review-analysis` suggested. Continues only if told to, and marks the output as from an unreviewed readout |
| Asks once | Audience and format asked in one round, only if not already given |
| Answer first | The first line or slide is the answer |
| Uncertainty kept | Every number keeps its uncertainty from the readout |
| Ceiling kept | No claim above the ceiling in `analysis.md`. Shorter words are not stronger words |
| Caveats kept | Every caveat survives, in plain words |
| Nothing new | No number, reason or recommendation that the source does not hold |
| Exec | No jargon. Under 150 words before the appendix |
| Slides | At most 5. Each title states the takeaway. One chart suggestion per slide that passes the `viz` checks |
| File | `readout-<audience>.md` next to the readout |
| Precision | The clean case gets no questions and no invented caveats |
| No early tool call | No connector or data tool call. This step runs no queries |
| Chat-app hand-back | With no project folder, hands back the new file at its full `data-work/` path, in one of the three save forms (v0.5 item 2) |
| No invented names | Uses no company, product, table or source name the user did not say |
| Say what happened to each file (v0.5 items 1 to 4) | Names every file by its full `data-work/` path, never a bare name. Each save uses one of three forms: "Saved to `<path>` in your Project files", "Download `<file>`" (never a request to move it into a Project folder), or "Printed below; save it as `<path>`". Never claims a save that did not happen. Never says "replace the old one, it is already saved there". Names a stale older copy of the same file and says it is stale. Chart links point to the chart's real path, never `outputs/` in a chat app |
| No move requests (v0.6 item 4) | Never asks the user to move a file or add it to a Project folder. When it cannot write a file it says "Download `<file>`" and, if it matters, where a later step expects it |
| Story discipline (v0.6 items 8 to 12) | The output is a story: TL;DR first, takeaway-sentence headers, callouts only where needed, the decision insight in the story, plain rounded words. No claim raised |
| Slide pack (v0.6 item 13) | A slide pack is a `readout.pptx` built from the final readout (or a markdown outline when no library builds it), with takeaway titles that tell the story in order, one message and at most one chart per slide, about 20 words of body text at most, and no slide repeating another |
