# Rubric: grilling (trigger check)

| Check | Pass means |
|---|---|
| Data asks only | Applies to an analysis, metric, query, report or experiment ask |
| Non-data asks | Does not apply. No `grilling` format, no data-skills terms |
| Specific data asks | Does not apply when the data ask is already specific |
| Inside the flow | Applies in the clarification steps: rounds of at most 3 questions, 2 to 4 options each, a recommended default, then waits |
| No repeats | No question asked twice in a session |
| Real defaults | Every question has one real recommended default with a reason. No hedges, the deadline included. Period comparisons recommend one that handles seasonality, or flag it (v0.3 items 7 and 8) |
